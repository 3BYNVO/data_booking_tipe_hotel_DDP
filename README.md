# data_booking_tipe_hotel_DDP

Program ini bekerja dengan cara menerima tipe kamar dan tanggal check-in/check-out dari pengguna, menghitung jumlah malam berdasarkan selisih tanggal, kemudian menghitung total biaya berdasarkan harga kamar per malam.

Alur sederhananya:

Input tipe kamar → Input check-in & check-out → Hitung durasi → Hitung total harga → Tampilkan data pemesanan
